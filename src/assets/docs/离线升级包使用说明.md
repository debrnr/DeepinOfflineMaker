# deepin 离线升级包使用说明

## 这个包是什么

`updata` 目录是一个本地 apt 源：以 deepin loong64 ISO 内的包版本为“刚装好”基准，收录官方源里比它更新的包（装机后本应联网升级的安全更新/bug 修复），以及 `Packages`/`Packages.gz`/`Release` 索引。

`offline-soft` 目录（如有）是勾选的软件主包，`offline-soft/deps` 是单独下载的依赖（也可能是同级 `soft-deps/` 或已并入 `updata/`）。主包清单在 `offline-soft/manifest.json`，里面记录了依赖目录位置。旧交付包的软件目录叫 `soft`，工具同样兼容。

`printer-drivers` 目录（如有）是离线打印机驱动，`printer-drivers/deps` 是驱动依赖，各自带 apt 索引；`manifest.json` 里记录了每项驱动对应的品牌/VID/PID 提示，供目标机检测匹配。

## 推荐方式：图形化工具（无需命令行）

1. 双击 `tool/` 里的 `deepin-offline-upgrade_*.deb` 安装（会弹一次密码框，输入登录密码）。
2. 从应用菜单打开“离线工具”：
   - **离线升级页**：自动找到 updata 目录，点“开始升级”，再次输入密码，等待完成（几分钟，勿断电），完成后点提示重启。
   - **软件安装页**：自动找到 offline-soft（或旧 soft），列出软件，勾选后点“安装选中软件”；工具会把依赖目录一起加入临时 apt 源，依赖自动处理。
   - **打印机驱动页**：自动找到 printer-drivers，点“检测打印机”查看 USB/网络设备和推荐驱动；点“一键检测并安装”会按品牌选好驱动并装 CUPS 基础环境，也可手动勾选。装完自动重启 CUPS 服务。
3. 全程不访问互联网、不需敲命令。工具不会改动你系统原有的软件源设置（用临时源）。
4. **如果这是“增量更新包”**（根目录有 `update-info.json`），工具一打开就会弹窗提示本次有多少系统更新、软件更新和打印机驱动更新；同一个包只提示一次。按提示去各页安装即可。

## 备用方式：命令行

在 `updata` 目录下执行：

```bash
sudo apt install -y --no-download ./*.deb
```

安装软件（主包目录 + 依赖目录）：

```bash
sudo apt -o Dir::Etc::sourcelist=/path/to/offline-soft.list update
sudo apt install -y /path/to/offline-soft/*.deb /path/to/offline-soft/deps/*.deb
```

（图形工具内部已封装上述逻辑，推荐直接用工具。）

## 注意事项

- 适用于 loong64（龙芯 3A5000 及以上）架构的 deepin 25.x。
- 升级前建议备份个人重要数据。
- 目录根部的 `project.json` 是制作端用来生成**下一批**增量更新的基线快照，目标机安装时不需要动它；但把它压缩存档或转发网盘时**请勿删除**，只拷 deb 会让半年后接不上基线。
- 若中途失败或断电，已装好的更新依然有效，重新运行工具即可续装（会跳过已装包）。
- 升级包来自 deepin 官方 loong64 仓库，已校验 SHA256；软件包来自星火商店 loong64 目录或内置精选；打印机驱动来自 deepin loong64 源与星火商店 loong64 驱动 deb，下载失败会记入日志并跳过。
- 出问题时看日志：`/tmp/deepin-offline-upgrade-install.log`。
